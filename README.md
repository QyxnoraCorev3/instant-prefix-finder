# Instant Prefix Finder

A fast, lightweight web-based search tool designed to match masked/broken CLI names (e.g., `SinchVXXXXX`, `AUXXXXX`) from SMS test panels with full service names from a pre-defined database of **1281+ Services**.

## Features
- **1281+ Pre-loaded Services:** Complete database built-in.
- **Smart Masking Handling:** Automatically strips out `X` masking characters from pasted inputs.
- **Instant Filtering:** Real-time search results as you type.
- **One-click Copy:** Easily copy full service names to your clipboard.
- **Mobile & Desktop Friendly:** Clean, responsive dark-themed UI.
